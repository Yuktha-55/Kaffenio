# Kaffenio

Kaffenio is a coffee shop landing page with a warm espresso-inspired visual style. It includes a hero section, featured menu items, the Kaffenio story, location details, and responsive navigation.

## Features

- Coffee-colored palette using espresso, mocha, caramel, cream, and latte tones
- Kaffenio logo from the local `Logo.png` asset
- Large coffee-focused hero section with calls to action
- Fixed desktop side navigation
- Responsive mobile slide-out menu
- Active navigation state that updates while scrolling
- Responsive layout for desktop, tablet, and mobile screens

## Project Files

- `index.html` - Page structure and content
- `styles.css` - Layout, responsive styles, colors, typography, and imagery
- `script.js` - Mobile navigation and active section behavior
- `Logo.png` - Kaffenio brand logo

## Run Locally

Open `index.html` directly in a browser, or use a local development server such as the VS Code Live Server extension.

No build step or dependency installation is required.
